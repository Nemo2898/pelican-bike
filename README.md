# 🚲 鹈鹕骑自行车 · 海岸公路追鱼之旅

一只戴头盔墨镜、系红围巾的鹈鹕,在海岸公路上骑自行车抓鱼。

**在线玩:** https://nemo2898.github.io/pelican-bike/

## 特性

- 🪁 布料物理模拟的红围巾(Verlet 布片 + 风速/抖动)
- 🌗 昼夜循环:黄昏 → 星空月夜 → 黎明 → 白天,含太阳/月亮、星空、灯塔旋转光束
- 🌊 海面波浪(着色器 Gerstner 波)+ 岸边碎浪/泡沫带
- 🎣 玩法:W/S 加减速、A/D 变道、空格跳跃、T 展翅抬前轮
- 🏆 14 个成就(解锁弹窗 + 成就面板,本地持久化)
- 🎥 5 种镜头:追尾 / 电影运镜(自动切换机位 + 电影黑边)/ 鹈鹕视角 / 环绕(可拖拽)/ 侧跟
- 🎵 Web Audio 实时合成音乐(节奏跟随踏频)+ 环境音(海浪/风声/夜间虫鸣/海鸥)与音效
- 📱 触屏虚拟按键;按帧率自适应画质(像素比/阴影/波浪精度/布料迭代/鱼群数量)
- 🤖 不操作 4 秒后自动追鱼驾驶
- 🐟 抓到鱼会装进车头的小篮子

## 运行

纯静态,任意 http 服务器:

```bash
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123/
```

## 操作

| 按键 | 功能 |
| --- | --- |
| W / S | 加减速 |
| A / D | 变道 |
| 空格 | 跳跃 |
| T | 展翅抬前轮(翘头) |
| C / 1-5 | 切换镜头 |
| M | 静音 |
| H | 成就面板 |

调试:`?debug=1` 显示调试钩子(`__ff` 快进、`__key` 模拟按键、`__setTime` 设置时间);`?q=0..3` 锁定画质档位。
